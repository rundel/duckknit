# Changelog

## duckknit 0.1.0

- Initial release.
- [duckdb](https://r.duckdb.org/) knitr engine with persistent CLI
  sessions across chunks.
- Chunk options: `db`, `session`, `mode`, `timeout`, `ansi`.
- [`duckknit_sitrep()`](https://rundel.github.io/duckknit/reference/duckknit_sitrep.md)
  for diagnostics.
